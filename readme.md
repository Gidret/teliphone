# Веб-приложение «Продажа мобильных телефонов»

Локальный веб-сайт с системой авторизации, личным кабинетом, интерактивной доской объявлений, возможностью совершения онлайн-покупок и базой данных для управления продажами мобильных телефонов. Проект разработан на чистом PHP (Native PHP) с использованием СУБД MySQL, развернутой в Docker.

## 🛠 Технологический стек
* **Backend:** PHP 8.5+ (Native)
* **Database:** MySQL 8.0 (в Docker-контейнере)
* **Frontend:** HTML, CSS, JavaScript (Vanilla JS)
* **Инструменты управления БД:** phpMyAdmin (в Docker-контейнере)

---

## 🗄 Структура базы данных (mobile)
Проект включает в себя реляционную базу данных, состоящую из следующих таблиц:

* `users` (Покупатели / Администраторы) — хранит учетные данные пользователей (логин, хэшированный пароль, ФИО, телефон, email, роль).
* `telephones` (Телефоны) — каталог доступных к продаже официальных мобильных устройств (модель, бренд, цена, характеристики).
* `sellers` (Продавцы) — информация о сотрудниках или магазинах, осуществляющих продажи.
* `sales_ledger` (Сводная таблица / Продажи) — общая связующая таблица для фиксации факта продаж магазина (ID телефона, ID продавца, ID покупателя, дата сделки, общая стоимость).
* `ads` (Объявления пользователей) — пользовательские объявления о продаже б/у или личных телефонов (ID объявления, ID автора, модель, цена, описание, уникальное имя файла фотографии, дата публикации). Связана с таблицей `users` ограничением `FOREIGN KEY` с каскадным удалением.
* `purchases` (Покупки пользователей) — история успешных онлайн-покупок мобильных устройств покупателями (ID покупки, ID пользователя, модель купленного телефона, цена на момент сделки, дата и время). Связана с таблицей `users`.

## 💻 Функционал веб-приложения
1. **Страница авторизации (`authPage.php`):** безопасный вход в систему с использованием проверки хэшированных паролей через `password_verify()`.
2. **Страница регистрации (`index.php`):** создание нового аккаунта с валидацией полей (длина логина, сложность пароля, проверка ФИО на кириллицу, форматирование телефона к единому виду).
3. **Главная страница / Личный кабинет (`home.php` или `admin.php`):** 
   * Отображение персональных данных пользователя на основе сессий (`$_SESSION`).
   * Разграничение прав доступа: пользователи видят каталог телефонов и свои покупки, администратор имеет доступ к сводной таблице продаж и управлению БД.
   * **История покупок:** вывод персонального списка купленных устройств с фиксацией даты и стоимости сделки.
4. **Система покупок (`php/buy_phone.php`):** обработчик клика по кнопке приобретения товара. Проверяет авторизацию пользователя и безопасно через PDO заносит транзакцию в таблицу `purchases`.
5. **Просмотр объявлений (`ads_page.php`):** публичная лента объявлений от всех пользователей сайта, отображающая модель устройства, цену, текстовое описание состояния, загруженную фотографию и прямые контактные данные продавца (ФИО и телефон).
6. **Создание объявлений (`create_ad.php`):** защищенная страница с формой для выставления телефона на продажу. Доступна только авторизованным пользователям. Реализована валидация полей и безопасная загрузка изображений на сервер.
7. **Модерация и удаление:** авторы объявлений могут удалять свои неактуальные товары прямо из общей ленты. Пользователи с ролью `admin` имеют право удалять любые объявления. При удалении записи ассоциированный медиафайл картинки автоматически стирается с сервера.
8. **Информационная страница (`about.php`):** страница «О нас», описывающая ключевые возможности и назначение платформы.

## 🚀 Инструкция по локальному развертыванию (на Arch Linux)

### 1. Подготовка окружения (БД в Docker)
Убедитесь, что у вас запущен Docker. Сначала создайте общую изолированную сеть, а затем поднимите в ней контейнеры с MySQL и phpMyAdmin:

```bash
# Создание общей Docker-сети
docker network create mobile-network

# Запуск контейнера MySQL с примонтированным Volume для сохранения данных
docker run --name my-mysql --network mobile-network -v mysql_data:/var/lib/mysql -e MYSQL_ROOT_PASSWORD="mysecretpassword" -p 3306:3306 -d mysql

# Запуск контейнера phpMyAdmin, связанного с контейнером базы данных
docker run --name my-phpmyadmin --network mobile-network -e PMA_HOST=my-mysql -p 8080:80 -d phpmyadmin
```

### 2. Настройка базы данных
1. Откройте в браузере **`http://localhost:8080`** (phpMyAdmin).
2. Авторизуйтесь: пользователь `root`, пароль `mysecretpassword` (или ваш кастомный пароль).
3. Создайте базу данных с именем `mobile`.
4. Импортируйте SQL-структуру таблиц (`users`, `telephones`, `sellers`, `sales_ledger`, `ads`, `purchases`). *Убедитесь, что поле `tel` имеет тип `VARCHAR(20)` для корректного сохранения форматированных номеров.*

### 3. Конфигурация PHP-сервера (Если используете Linux)
В файле `/etc/php/php.ini` должны быть включены следующие директивы для работы с базой данных и поддержки коротких тегов PHP:
```ini
extension=pdo_mysql
short_open_tag = On
```

### 4. Настройка прав на сервере
Для корректной загрузки фотографий устройств убедитесь, что в корне проекта создана папка `uploads`, и у встроенного сервера есть права на запись в неё:
```bash
mkdir -p uploads
chmod 777 uploads
```

### 5. Запуск проекта
Перейдите в папку с проектом и запустите встроенный веб-сервер PHP:
```bash
cd /путь/к/проекту/telifoni
php -S localhost:8000
```

После этого откройте браузер по адресу **`http://localhost:8000`** для работы с сайтом.
