# Продажа мобильных телефонов (Веб-приложение)

**Веб-приложение / сайт** для управления продажами мобильных телефонов с интеграцией базы данных и личным кабинетом пользователя.

---

## 🛠️ Функционал приложения

### 1. Веб-интерфейс
* **Страница авторизации** — вход существующих пользователей и администраторов в систему.
* **Страница регистрации** — создание новых учетных записей.
* **Главная страница / Личный кабинет** — персональное пространство пользователя со списком доступных функций, профилем и историей.

### 2. База данных
Система включает в себя базу данных, состоящую из 3-4 взаимосвязанных таблиц:
* `телефоны` — каталог устройств (характеристики, цены, наличие).
* `продавцы` — информация о сотрудниках/магазинах.
* `покупатели` — данные зарегистрированных клиентов.
* `сводная таблица` — таблица заказов/транзакций, объединяющая информацию о продажах (какой телефон, какой продавец и какому покупателю продал).
